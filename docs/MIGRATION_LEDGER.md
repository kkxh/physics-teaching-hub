# 搬运台账

记录「从上游私有系统搬到本仓库」的进度与差异。每搬一个模块就更新一次。

## 状态取值

`未开始` / `进行中` / `已搬运` / `有意放弃`

## 记录要求

每次搬运时补三件事：状态、日期、与上游的差异。
差异要写「为什么不一样」，而不是只写「不一样」——例如班级名改成配置项、真实题号换成虚构示例。
