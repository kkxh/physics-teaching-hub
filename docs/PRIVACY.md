# 隐私与版权边界

这个仓库开放，但**它所服务的课堂不开放**。以下边界不因任何功能需求而放宽。

## 1. 永不进入本仓库的内容

**学生与教师数据**

- 学生姓名、学号、座位号、成绩、作业状态、行为记录、跟进记录；
- 真实班级标识、真实学校名称、地区教研专有表述、教师个人信息；
- 包含上述内容的数据库、截图、报告、导出文件。

**第三方内容**

- 教辅、教材、试卷、讲义、题目图片、答案图、讲评媒体；
- 任何来源不明或未明确授权分发的教学材料。

**凭据与环境**

- 密钥、令牌、`.env`、SSH 材料；
- 维护者本机的绝对路径与私有工作流文档。

## 2. 为什么这么严

- **对学生**：成绩与行为记录属于个人信息，一旦公开无法收回。
- **对使用者**：本项目的价值在于数据留在本机；仓库本身不含任何人的数据，使用者的数据也只留在使用者机器上。
- **对项目**：教辅与试卷受版权保护，随仓库分发会给使用者带来法律风险。

## 3. 演示与测试怎么获得数据

一律使用 `seed_demo_data.py` 生成的虚构数据：

- 姓名统一为「学生NN」，不可能与真实姓名重合；
- 班名使用带括号的示例名（如 `高一(A)班`），与真实班号风格区分；
- 数据确定可复现，同一随机种子生成同一份内容。

## 4. 提交前自检

```bash
bash scripts/privacy_scan.sh
```

通用规则负责识别绝对路径、密钥特征串、身份证号、手机号与私有风格班号。
学校名、真实人名这类词无法通用识别，请写进本地私有词表 `.privacy-terms.local`（每行一个关键词，已在 `.gitignore` 中）：

```bash
printf '%s\n' "某某中学" "某老师姓名" > .privacy-terms.local
bash scripts/privacy_scan.sh
```

## 5. 使用者的数据在哪里

使用者的数据库、输出与题库全部位于使用者本机的工作目录，由使用者的 `.gitignore` 拦住，不会进入版本库，也不会上传到任何服务器。

## 6. 发现泄露怎么办

如果在本仓库（含历史提交）中发现任何真实数据、个人身份信息或第三方受版权保护内容，请立即指出，维护者会删除相关内容并清理历史。
