# v0.1.0-alpha 发布说明

> 本文件是 GitHub Release 页的正文底稿（发布时按需微调）。这是本仓库的**第一个公开发布**，
> 定位是**早期 alpha**：接口会随搬运调整，功能有意保持精简。

## 这是什么

一个**本地优先**的中学物理教学数据中枢：把成绩、作业与订正、错因、学生画像、考试分析、
题库与讲义放进同一个 SQLite 文件，用命令行和一份可以双击打开的看板驱动。
**数据不出本机**，不需要服务器、不需要联网，只要 Python 3.11+。

## 这个版本能做什么

- **导入与记录**：成绩（CSV / Excel，含小题得分）、作业与订正、错因与行为记录。
- **分析与闭环**：学生画像（成绩水平 / 作业习惯 / 错因控制 + 综合分）、预警与跟进、
  周报、阶段巡检、考试逐题分析（得分率 / 难度 / 区分度）与讲评讲义。
- **题库与讲义**：题目按 JSON / CSV 导入，支持标签与关键词检索（**答案默认隐藏**）、
  按错因标签 × 画像难度档推荐（带可解释理由）、按 key 或按推荐组卷成讲义（默认不含答案）。
- **本地接口与看板**：只读本地 API（只绑 `127.0.0.1`）与单文件离线看板（数据构建时内嵌，双击即开）。

## 隐私设计（为什么敢让你导入真实数据）

- 程序**不联网、无遥测**；数据库、导入文件、报告与看板都在你的工作目录里，
  并且都在 `.gitignore` 的拒绝清单里——不会进版本库。
- 本仓库只含代码、文案、schema 与 **12 道自制示例题**；没有任何真实学生数据，
  也没有任何第三方试卷、教辅或教材内容。
- 仓库自带隐私扫描 `scripts/privacy_scan.sh`（含 `--history` 全历史模式）；
  发布前四个模式全部通过（证据见 [PHASE4_PLAN.md](PHASE4_PLAN.md) §9）。

## 已知限制

- 学段默认模板只有初中与高中两套；更细的本地化要自己写 `[[phases]]` 与文案表。
- 题库是纯文本：不支持图片题、公式渲染，PDF / Word 导入待定。
- 推荐是规则推荐（没有协同过滤 / IRT），推荐结果不落库、没有使用统计。
- 没有多用户、权限、云端同步——这是一个**单机工具**。
- 功能长期落后于作者的私有版本，不追求功能对等；`0.x` 阶段不承诺接口兼容。
