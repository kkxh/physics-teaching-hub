# 第三方依赖与许可证

发布前的硬性待办之一。本文件只记录**仓库自身分发**的依赖；使用者自己安装的其它工具不算在内。

## 结论

- 运行时**唯一的第三方依赖**是 `openpyxl`（MIT），而且是**可选**的：只有读 `.xlsx` 成绩表时才需要。
- 其余功能**全部只用 Python 标准库**（3.11+）。
- 开发依赖没有额外引入：测试用标准库 `unittest`，`requirements-dev.txt` 只是把运行时依赖一起装上。
- 仓库**不内嵌**任何第三方源码或数据；依赖由使用者用 `pip` 自行安装。

## 依赖清单

| 依赖 | 用途 | 许可证 | 引入位置 | 说明 |
| --- | --- | --- | --- | --- |
| `openpyxl>=3.1` | 读 Excel `.xlsx` 成绩表 | MIT | `requirements.txt` | 标准库没有可用的 xlsx 解析器；不装它时 Excel 导入会明确报「需要 openpyxl」，其余命令照常可用 |

## 复核方式

```bash
cat requirements.txt requirements-dev.txt      # 运行时与开发依赖
grep -rn "^import \|^from " --include='*.py' . | grep -v "^\./tests/"   # 看有没有落到第三方模块
```

## 新增依赖的准入规则

沿用 [AGENTS.md](../AGENTS.md) 第 5 条：

1. 优先标准库；
2. 许可证必须是宽松许可（MIT / BSD / Apache-2.0）；
3. 提交信息里说明「为什么标准库不够用」；
4. 加进来就要在本文件补一行（依赖、用途、许可证、引入位置）。
